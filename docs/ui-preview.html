3.0 · Today 风格主屏

主屏已换成纯原生 View，不再是「桌面网页套个原生壳」。下面这台手机可以点：底部 5 个 Tab、左上设置 / 中间头像 / 右上搜索、气泡卡、灵感胶囊、输入框发送。真机里点气泡会进面板对应页面，输入会送进 /chat 的终端。

这轮到底改了什么

  • 首屏换成原生 View：渐变背景、圆形悬浮按钮 + 居中头像、白色聊天气泡流、胶囊输入栏、胶囊底部 Tab、卡片式设置页。完整 SPA 退到按需加载的工作台层。
  • 不卡：删掉每 2 秒遍历 View 树 + 注入 JS 的轮询；CSS 清掉几十条 [class*=] 通配选择器与通配动效；ticker 降到 2 秒且首页不执行 JS；首屏完全不加载 WebView。
  • 不是空壳：气泡与列表来自本机 /api/status、/api/sessions；所有卡片都是真入口（面板真实路由或原生能力）。
  • 输入真能用：回车后回显气泡，并把文字注入 /chat 的 xterm，触发 PTY；失败兜底复制到剪贴板。

功能没有少

2.0 修好的文件选择、多选上传、下载落盘、原生工作区管理，以及端口 / 工作目录 / 局域网 / 全自主 / 保持唤醒 / 日志 / 导出 / 重装 / 重启，全部保留在工作台层。工作台左上「←」回首页，返回首页不销毁 WebView，终端会话不丢。

如实说明

/chat 仍是上游内嵌的 TUI 终端。主屏做成 Today 的气泡流、输入也能送进终端，但终端回复不会变成气泡 —— 那要替换上游前端组件与 PTY 交互，会动到功能代码，这版没碰。
