# 工作台 UI 优化说明（DSH-Go 风格）

## 参考对象

[ccch1mneyyy/dsh-Go](https://github.com/ccch1mneyyy/dsh-Go)（Flutter，21.5k star）。
它的 README 里有一节「原生界面，也有网页版」——两套 UI 可一键切换。
按你的要求：**不做两套、不搞切换，就做一套，视觉照它原生版来**。

## 从截图里扒出来的设计语言

三张截图（聊天页 / 会话抽屉 / 设置页）采样得到的配色与形状：

| 项 | 值 |
|---|---|
| 背景 | 淡紫蓝纵向渐变 `#E2E9FB → #F0F3FC → #F8F7FD` |
| 卡片 | 纯白 `#FFFFFF` / 近白 `#FAFBFF`，大圆角（约 18–22dp） |
| 主色 | 蓝紫 `#5266AF`（「新对话」实心胶囊按钮） |
| 文字 | 主 `#1B2235`、次 `#6B7288`、弱 `#8B92A6` |
| 形状 | 圆形图标按钮、胶囊输入框、iOS 式分组列表 + 右侧箭头 |
| 点缀 | 分组标题小灰字、彩色圆形图标底、选中态浅紫胶囊 |

## 落地方式：原生壳重做 + 面板换肤，功能一个不动

**关键取舍**：Hermes 的全部功能（聊天、会话、技能、定时、MCP、配置、KEYS）
都在 `127.0.0.1:9119` 那个 WebView 面板里。如果用原生 View 把工作台整个重写，
这些功能必然会缺。所以做法是：

1. **原生壳按 DSH-Go 原生版重做**（你看得见、点得到、滑得到的部分）：
   - `MainActivity.kt`：顶部改成「圆形菜单按钮 + 胶囊标题（● 本机 · workspace）
     + 圆形新建按钮」；背景换成淡紫蓝渐变；状态卡 / 次要按钮 / 日志区换成白色大圆角卡片；
     主按钮换成 `#5266AF` 蓝紫实心；状态栏改浅色+深色图标。
   - `EtaUi.kt` / `themes.xml`：设置弹层、输入框、分组行同步换浅色白卡片。
   - 配色常量集中在一处，改一处全 App 生效。
2. **工作台仍是 WebView 承载完整面板**，但注入 `hermes-skin.css` 把它刷成同一套
   浅色 DSH-Go 风，避免「原生壳浅色、一进工作台变深色终端」的割裂。
3. 注入只做 `appendChild(style)` + `textContent`，**不改 DOM、不拦截请求、
   不覆盖 JS 对象、不动路由** → 功能一个没少，只是换皮。

## 关于「像 Open Code」

上游 `web/src/index.css` 里写明 `JetBrains Mono — bundled for the embedded TUI
(/chat tab)`，CHAT 页是 xterm.js 内嵌终端 + 深青底（LENS_0 `#041c1c`），
这就是终端感的来源。这次把它收成一张带圆角留白的柔和深蓝卡片（文字由 canvas
绘制，保留深色底保证可读），并让整页翻成浅色。

> 要把 CHAT 彻底做成 DSH-Go 那样的气泡式聊天，得改上游前端组件（会动到功能代码），
> 那是另一档工作量，等这版真机看过再说。当前这版先把「丑」解决掉。

## 回滚通道

把 `assets/hermes-skin.css` 清空，`ThemeSkin` 会移除注入的 style，
面板完全回到上游原版；原生壳的配色常量改回去即可。

## 签名与仓库卫生（前一批改动）

- `build.gradle.kts` 不再写死 `hermes2026`，改读环境变量；CI 顶层 env 从 Secrets
  注入三个签名变量（未配置时有 fallback，保证构建链不中断）。
- 第一次构建报 `Unresolved reference: util`（Gradle Kotlin DSL 里 `java.util.Properties`
  被作用域遮蔽），已改成纯 `System.getenv(...) ?: throw` 的最简写法。
- `.gitignore` 改为 `**/local.properties` + `**/keystore.properties`；
  误提交的 `android/local.properties` 已删除。

> 如实说明：`keystore/hermes-release.jks` 本身随仓库分发，密码是否明文不改变安全边界。
> 收益是凭据不再硬编码在源码、随时可换 Secret。正式分发要换签名，但那会破坏覆盖安装。
