## 我这侧已静态核过（无需真机）

| 项 | 结论 |
|---|---|
| 构建配置 | compileSdk 36 / minSdk 26 / targetSdk 28 / 仅 arm64-v8a / 纯 framework 无 androidx |
| 签名 | `keystore/hermes-release.jks` 未改动，CI Secrets 注入凭据，指纹与 1.0 一致 |
| 覆盖安装 | applicationId 不变、证书不变、versionCode 1→2，Android 允许直接覆盖 |
| CI | 双 job（arm64 chroot 冒烟 + x86 打包），push 到 main 自动触发 |
| 注入 | `WebBridge` 幂等注入 CSS + 桥接脚本；不改 DOM 结构、不拦截请求、不动路由 |
| 上传根因 | 上游 `FilesPage.tsx` 用隐藏 `input[type=file]` + `.click()`，WebView 缺 `onShowFileChooser` 会静默失败 |
| 工作区根因 | 上游 `/api/chat/workspaces` 依赖桌面端 `projects.db` + 仓库发现缓存，headless proot 里恒为空；`resolve_chat_cwd` 还要求目录真实存在 |
| 功能承载 | 工作台 = WebView 全屏承载上游 SPA，原生壳只做导航与能力补齐 |
